# smart-product-rating
• Designed a system to analyze customer feedback using speech-to-text conversion and senti ment analysis • Processed structured and unstructured data to generate product ratings • Improved decision-making by combining voice and textual insights
ABSTRACT: 
In today’s digital world, customer feedback plays a very important role in improving 
product quality, building user trust, and increasing business success. Most traditional 
product rating systems rely only on written reviews or fixed star ratings. However, these 
methods may not fully capture the emotions or ease of expressing opinions, especially for 
users who find it more comfortable to speak rather than type.  
This project presents a Smart Product Rating System that uses both voice and text inputs to 
understand customer feedback and generate smart product ratings. The system is developed 
using Python, and it combines different libraries such as Pygame for creating the graphical 
user interface (GUI), SpeechRecognition for capturing and converting spoken input to text, 
and NLTK (Natural Language Toolkit) with VADER Sentiment Analyzer to analyze the 
emotional tone of the user's feedback.  
When the user presses the spacebar, the system starts listening to the voice input. It then 
converts the speech to text using Google's Speech-to-Text service and performs sentiment 
analysis to find out whether the feedback is positive, negative, or neutral. These results are 
shown on the screen using easy-to-understand progress bars and emojis, helping users 
quickly grasp the meaning of the feedback.  
The main goal of this project is to create a simple and interactive system that makes giving 
product feedback easier and more natural—especially for people who prefer talking. This 
system can be used in e-commerce platforms, customer service kiosks, or mobile 
applications to gather real and emotional product reviews. By supporting both voice and 
text, this project helps make product reviews more expressive and inclusive, opening the 
door to smarter and more user-friendly feedback systems
